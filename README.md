# Grace with Apache Shiro

This guide walks you through the process of creating a simple web application with resources that are protected by Apache Shiro.

## Grace Version

- Grace Framework **2023.0.3**


```gradle
dependencies {
    implementation 'org.apache.shiro:shiro-spring-boot-web-starter:3.0.1'
}
```
